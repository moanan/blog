# 2022-03-05 {% asset_link Braupaket-Universalrezept-Weizen.pdf Hefe Weizen %}

Hefe Weizen是我最喜欢的德国啤酒之一。实际上，我自酿的啤酒都没有过滤酵母，所以都是Hefe的。

煮麦汁的过程相对繁琐，需要43，63，72，78度分段加热。可能是小麦带有的淀粉酶喜欢不同的温度？加热时要经常检查温度并调节火力，现在突然明白了高端酿造设备里可编程温度曲线的重要性。有空自己做一个吧！

为了提升酿造体验，这次买了新的虹吸管用于分装。新的虹吸管有类似打气筒的机构抽真空，可以将年轻啤酒从发酵瓶中抽出，和原装的虹吸管（就是一只管。。。）比实在体验好太多了。其实还购买了Refractometer，用来测量啤酒在酿造过程中的糖度变化从而计算酒精浓度，但忘了使用。

# 2022-01-23 {% asset_link Bierbrauset-Pils.pdf Pils %}

2019年圣诞节在Aldi买的自酿啤酒套装，在地下室吃灰了2年多，终于在居家隔离期间被翻出来重见天日。套装内的发酵玻璃瓶为1加仑容量的，没想到加仑还有不同定义，最后实测容量为约3.5升。

查了一波单词后，开始按{% asset_link Bierbrauset-Pils.pdf 步骤 %}操作。家里大大小小锅碗瓢盆正正好够做，少一样都不行。

3周后，喝到自酿的1号啤酒。哇！这就是梦想中啤酒应该有的味道！我是不太喜欢Pils的（Pils在亚琛很流行），但这个实在是太好喝了！上一次喝到这么好的啤酒应该是在啤酒厂参观喝到的生啤。其实这就是生啤！没有巴氏灭菌，没有过滤酵母，原汁原味。

# 自酿步骤

酿造过程主要分两天、五个步骤完成：第1天酿造需要5小时左右，经过7-10天的主发酵后，需要1小时左右装瓶，最后需要3周左右的二次发酵。原料很简单，按德国标准就只有4件：麦芽、啤酒花、酵母、水。

{% asset_img steps.png 350 %}

## Brautag / Brew day

### 器具
- 原料
- 温度计
- 消毒剂
- 一口10L大锅
- 二口大锅（也可以是两个小锅）
- 漏斗
- 滤网
- 量杯
- （冰块）

### Maichen / Mashing
- 将3.5L水加热至67度
- 加入麦芽，保持温度煮60分钟左右
- 最后加热至78度煮1分钟终止淀粉酶作用

### Läutern / Lautering
- 将麦芽捞出至滤网上
- 用麦汁冲洗麦芽滤出收集起来
- 烧第二锅水约3L至78度
- 将水冲洗麦芽一次滤出收集起来
- （此时麦芽内还有一些残糖，可以考虑再滤一次）
- 收集到的液体称为Würze/wort，未来将成为啤酒

### Hopfenkochen / Boiling
- 将麦汁煮开后保持微开1个小时左右
- 根据啤酒种类择机加入啤酒花
- 在水槽内加满冷水（以及冰块）
- 麦汁煮够时间后放入水槽降温至25度以下，可以搅拌麦汁以加速冷却
- （测量麦汁的折射率）
- ⚠️往后的步骤所有与麦汁接触的物体都需要仔细消毒！

#### Gärung / Fermentation
- 备4L温水，溶解适量消毒液
- 将发酵瓶、瓶塞、漏斗、液封阀充分消毒
- （建议戴手套和口罩）
- 将麦汁通过漏斗倒入发酵瓶至刻度线（文字位置），如果麦汁不够，加水，如果麦汁过多则倒掉
- 将酵母加入发酵瓶
- 将发酵瓶轻轻摇晃促进酵母与麦汁混合
- 塞好瓶塞及液封阀，并加水至液封阀刻度线
- 将发酵瓶避光存放10天左右，温度最好在18-20度


## Abfülltag / Bottling day

### 器具
- 一口10L大锅
- 消毒剂
- 虹吸管
- 止水夹
- 330mL酒瓶x10
- 糖

### Reifung / Bottle ageing
- 备4L温水，溶解适量消毒液
- 将虹吸管、止水夹、酒瓶充分消毒
- 每个啤酒瓶中加入3mL糖（或一片糖丸）
- （测量啤酒残糖浓度）
- 用虹吸管分装啤酒
- 盖上酒塞，在室温（18-20度）发酵3周左右
- 二次发酵结束后放入冰箱冷藏后饮用（否则压力可能过大）
