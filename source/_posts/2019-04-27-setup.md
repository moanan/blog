## Sublime Text配置
首先安装 [Package Control](https://sublime.wbond.net/installation)

### Latex
- 按下`Command+Shift+P`打开 Command pallet
- 输入命令`Install Package`，进入Package列表
- 再输入`LaTeX Tools`，进行安装
- 编辑Preferences -> Package Settings -> LaTeXTools Settings - User 中的 `viewer` (`""`)，选择自己喜欢的pdf阅读器，如`viewer` (`"preview"`)

### SFTP
- 按下`Command+Shift+P`打开 Command pallet
- 输入命令`Install Package`，进入Package列表
- 再输入`SFTP`，进行安装
- 在本地需要SFTP至远程的文件目录中新建`sftp-config.json`文件并进行配置
