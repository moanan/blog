参考视频：[廚房裡的人類學家：煎鴨胸配香橙醬汁](https://www.youtube.com/watch?v=vqP-A6MV7cc)

#### 材料：
- 鸭胸
- 土豆
- 橙汁
- 姜片
- 八角
- 肉桂
- 酱油
- 盐&胡椒

## 橙汁酱
- 准备`2片姜`、`1个八角`、`肉桂`、`橙汁～100ml`，放入小锅
{% asset_img DSC_8018.JPG 小锅煮汁 %}
- 中大火浓缩至大概2-3大匙，再加少量`酱油`、`盐`调味
{% asset_img DSC_8079.JPG 浓缩好的橙汁酱 %}
- （Tip：煮的时候泡沫很多，注意不要喷出来）

## 鸭胸
- 平底锅中小火预热，烤箱180摄氏度预热
- `鸭胸`擦干水分
- 鸭皮表面交错划开，注意不要切到鸭肉
{% asset_img DSC_8029.JPG 切鸭皮 %}
- （Tip：鸭皮边缘可以切开，便于流油）
- 鸭肉两面撒`海盐`、`胡椒`
- 锅温热时放入鸭胸（不需要加油），鸭皮朝下
{% asset_img DSC_8031.JPG 煎鸭皮 %}
- 中小火煎8-10分钟
- 逼出的`鸭油`沥出备用
- 鸭胸翻面，放入预热好的烤箱，烤10分钟（此时鸭胸为5-7分熟）
{% asset_img DSC_8038.JPG 鸭胸休息中 %}
- 取出鸭胸，静止2-3分钟
- 鸭胸切片，约1cm厚
- （Tip：所有烤好的肉类一样，静止2-3分钟再切片可以让汁水重新吸收到细胞内，减少分水流失）
- 
## 土豆
- `土豆`去皮切块
- 冷水下锅，水开后再煮10分钟，捞出沥干水分
{% asset_img DSC_8032.JPG 煮土豆 %}
- 加入`鸭油`，若不够(什么叫不够？？)再加其它油，适量`盐`，拌匀
{% asset_img DSC_8046.JPG 土豆镀膜工艺 %}
- 倒入煎鸭胸的平底锅，注意不要搅拌，直至土豆底部形成焦黄硬壳
- 土豆翻面，煎至金黄焦脆
{% asset_img DSC_8073.JPG 金黄焦脆？！ %}

## 最后一步
- 鸭胸和土豆盛盘，浇橙汁酱
{% asset_img DSC_8076.JPG 金黄焦脆？！ %}
- 最后可以搭配喜欢的`沙拉`
