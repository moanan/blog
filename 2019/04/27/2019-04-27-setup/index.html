Sublime Text配置

首先安装 Package Control

Latex

  • 按下Command+Shift+P打开 Command pallet
  • 输入命令Install Package，进入Package列表
  • 再输入LaTeX Tools，进行安装
  • 编辑Preferences -> Package Settings -> LaTeXTools Settings - User 中的 viewer ("")，选择自己喜欢的pdf阅读器，如viewer ("preview")

SFTP

  • 按下Command+Shift+P打开 Command pallet
  • 输入命令Install Package，进入Package列表
  • 再输入SFTP，进行安装
  • 在本地需要SFTP至远程的文件目录中新建sftp-config.json文件并进行配置
